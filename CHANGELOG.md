# Changelog

## 0.1.1 — 2026-09-27

- Add the installable `handoffx` Agent Skill.
- Guide producer, receiver, relay, revision, multi-receiver, and zero-install workflows.
- Include a compact 0.1 protocol reference for agents that do not invoke the CLI.

## 0.1.0 — 2026-09-27

- Define the transport-independent handoffX 0.1 protocol.
- Define portable Markdown handoff and response artifacts.
- Support one producer, zero-install receivers, and independent multi-receiver responses.
- Define OFFER, REQUEST_INFO, REVISE, and ACCEPT semantics.
- Bind responses and revisions to exact SHA-256 file bytes.
- Ship JSON Schemas, examples, and a Node.js/Bun reference CLI.
